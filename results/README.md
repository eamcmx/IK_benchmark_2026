# results

Per-cell results of the benchmark: 41 solvers x 6 robots x 4 trajectories = 984 cells per phase, 100
waypoints each, budget 2000 FK evaluations per waypoint, pose gate 1e-5 m and 1e-5 rad.

| File | Contents |
|---|---|
| `phase1.csv` | Phase 1: each solver as published. |
| `polished.csv` | Phase 2: each solver followed by the common DLS polish. |
| `manip_traces.mat` | Manipulability traces along the circle trajectory (Phase 2), from `run_manip_traces.m`. |
| `tables/<phase>/`, `figures/<phase>/` | Generated by `figures_pipeline/gen_results.m`; `figures/<phase>/stats_report.txt` holds the Friedman, Iman-Davenport and Nemenyi numbers. |

## CSV columns (one row per solver, robot and trajectory)

| Column | Meaning |
|---|---|
| `label` | Solver (`Lit:` = implemented from a source paper; `Newton12-anaJ`, `PINV-orig` = baselines). |
| `phase` | `phase1` or `polished`. |
| `robot`, `traj` | Robot and trajectory (`cuspidal` = the workspace-boundary trajectory). |
| `success` | Fraction of the 100 waypoints that meet the gate (recomputed from FK). |
| `med_pos_err`, `med_rot_err` | Median over the waypoints of the final position (m) and rotation (rad) error. |
| `med_t_ms` | Median harness wall time per waypoint (ms), the whole solver call, polish included in Phase 2. |
| `med_fk`, `max_fk` | Median and maximum FK evaluations of the base solver per waypoint (harness count). |
| `med_jac` | Median Jacobian evaluations per waypoint (harness count; not budgeted). |
| `frac_budget_exceeded` | Fraction of waypoints on which the base solver exceeded the budget. |
| `frac_not_applicable` | 1 when the solver reports the robot as not applicable (cell shown as n/a, never scored). |
| `med_t_self_ms` | Median wall time measured inside the solver (reference only). |
| `med_polish_iters`, `med_fk_polish` | Phase 2: median polish iterations and FK evaluations of the polish. |
| `crashed` | 1 if the cell raised an error (none did). |

Wall times depend on the machine and are compared between solvers in Phase 2 only.
